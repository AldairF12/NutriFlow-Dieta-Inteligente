# 🥗 NutriFlow — Intelligent Diet Planner

> Web application designed to support personalized diet planning through an interactive and responsive user experience.

🌐 **[Live Demo](https://aldairf12.github.io/NutriFlow-Dieta-Inteligente/)**

---

## 📌 Overview

**NutriFlow** is a web application focused on helping users organize and explore personalized diet plans through an intuitive interface.

The project was developed as a frontend-focused web application and explores Progressive Web App capabilities.

---

## ✨ Features

- 🥗 Diet planning interface
- 🍎 Food and meal information
- 📱 Responsive design
- 💻 Interactive web interface
- ⚡ Client-side functionality
- 📲 Progressive Web App capabilities
- 🎨 User-focused interface
